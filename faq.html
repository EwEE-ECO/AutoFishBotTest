Frequently Asked Questions

What if the bot doesn't start?

Make sure you run the bot as administrator. Also ensure your antivirus is completely disabled the bot uses input emulation which can trigger false positives.

What graphics settings are needed?

Screen mode: "Borderless window". Disable vertical sync. "21:9" format is not supported. Set "16:9". If the bot doesn't work with Redux or Nvidia filters disable them.

Can the bot only fish?

No, the bot is universal. The name "AutoFishBot" reflects the main function, but the bot can perform various types of work.

How do I update the bot?

The bot updates automatically. Just launch the latest version it checks for updates on startup. You can also always download the latest version from our Telegram channel or the "Download" button on the main page.

Windows 11

If your Windows 11 version is older than 24H2, before launching the bot:

Open program "Properties" (right-click)
Go to the "Compatibility" section
Check "Run this program in compatibility mode for:" Windows 8

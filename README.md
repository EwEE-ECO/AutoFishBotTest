# 🐟 AutoFishBot — Universal bot for MajesticRP

**AutoFishBot** — универсальный бот для автоматизации рыбалки и других работ на сервере **MajesticRP**. Написан на AutoHotkey, безопасен, удобен и эффективен.

🔗 **Оригинальный репозиторий:** [PaulTwelve/AutoFishBot-MajesticRP](https://github.com/PaulTwelve/AutoFishBot-MajesticRP)

---

## ✨ Возможности

- **Многофункциональность:** рыбалка, сбор апельсинов, лесоруб, карьер и другие работы в разработке
- **Безопасность:** не встраивается в игру, не вызывает бан античита, скрывает следы использования
- **Гибкость:** регулярные обновления, автообновление, поддержка мультимониторов (Aster) и графических модов (Redux)
- **Удобство:** интуитивный интерфейс, настройка хоткеев, автостоп, таймер выключения, быстрый вызов `Ctrl+Shift+1`

## ⚙️ Установка

1. Скачай бота (кнопка **Download** на сайте или в [Telegram-канале](https://t.me/AutoFishBotMajesticRP))
2. Отключи антивирус (ложное срабатывание на эмуляцию ввода)
3. Настрой графику в игре: `ESC → Настройки → Графика`:
   - Режим экрана: **Оконный без рамок**
   - Формат: **16:9** (21:9 не поддерживается)
   - Вертикальная синхронизация: **выкл**
4. Запусти `AutoFishBot.exe` **от имени администратора**
5. Нажми `Ctrl+Shift+1` для открытия меню
6. Выбери режим работы

> **Windows 11:** Если версия ниже 24H2, включи в свойствах .exe → Совместимость → "Запустить программу в режиме совместимости с: Windows 8"
